#  About the Data

---

##  Where the Data Comes From

The system is evaluated on real kindergarten CCTV footage.

---

##  What Makes This Data Unique

- Multiple children in dynamic scenes  
- Frequent occlusions  
- Side and partial face visibility  
- Varying lighting conditions  

---

## Real-World Challenges

- Faces are not always visible  
- Children move unpredictably  
- Background clutter affects detection  

---

## Privacy Note

Due to privacy concerns involving children, the dataset is not publicly available.
